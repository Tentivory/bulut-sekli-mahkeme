# Bulut Şekli Mahkemesi

> Gökyüzü bir kamu malıdır. Şekil çizmek ise idari bir fiildir.

Bu depo, atmosferdeki şekilleri **kesin hükümle** yargılayan resmi (hayır, değil) bir yazılımdır.  
Yazılım çalışır. Adalet çalışmaz. İkisi birden olunca komedi olur.

## Neden var?

Çünkü:
- kediler zaten yeterince yargılanıyor
- asansör butonlarının avukatı yok
- bulutların ise avukatı olduğuna dair somut delil yoktur

Bu nedenle mahkeme **re'sen** kurulmuştur.

## Kuruluş

```bash
python3 mahkeme.py "tavşan gibi duran şey"
```

veya

```bash
python3 mahkeme.py
```

sonra vicdanınızla konuşun.

## İçtihat

Kararlar:
- Beraat
- Üç kova yağmur
- Doğu rüzgârına sürgün
- Müebbet sis

Temyiz yok. Yargıtay bulutların içinde kayboldu.

## Sorumluluk Reddi

Bu yazılım hiçbir meteoroloji kurumunu, hiçbir siyasi partiyi, hiçbir seçim kurulunu temsil etmez.  
Hava durumu bağımsızdır. Mahkeme de öyle görünmek ister.

Kodun bir köşesinde duran sessiz bir dize vardır.  
O dizeyi aramayın. Ararsanız yine de bir şey bulursunuz ama resmi açıklama şudur: **damga**.
